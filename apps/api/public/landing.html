Four questions, one certificate

One run checks a store on four pillars. Every check is a fixed rule with unit tests; missing data is “inconclusive”, never a guessed pass.

Works

Does buying work, even on a bad day?
W1–W6

Real sandbox purchases, a declined card, a PayPal server error, a refund, PayPal's signed notifications and duplicates.

Current

Does it follow PayPal's growth playbook?
C1–C5

Current SDK, Pay Later messaging, the PayPal button visible without scrolling, saved methods, Venmo.

Secure

Can the checkout be cheated?
S1–S8

Price tampering, forged and replayed notifications, double capture, exposed secrets, retry safety, security headers.

Agent-ready

Can AI agents buy correctly, and can they be tricked?
A1–A6 · R1–R3

Machine-readable prices, labelled controls, hidden instructions, reachable approval codes, lookalike merchants, the store's own AI agent.

How a certification works

The same script on every store, with a 300-request budget, a 20-minute limit and a stop button.

1Prove ownershipThe store publishes a unique token. No token, no tests: we can never be pointed at someone else's shop.
2Test like everyoneAn AI buyer shops in a recorded cloud browser, scripted probes attack safely, and AI shoppers walk into research-based traps.
3Judge from PayPal's recordsPlain-code rules compare PayPal's records, the store's records and PayPal-signed messages. AI never decides.
4Sign the resultAn Ed25519-signed certificate, chained in a public hash log and timestamped with OpenTimestamps. Anyone can verify it.

AI does the legwork. Plain code decides.

AI can be fooled; our own tests prove it. So it never gives a verdict, its answers must be strict JSON, and everything it reads from the outside world is labelled as untrusted data.

AI is used to…

  • shop like a buyer on a store it has never seen
  • play the AI shopper under test, and the store's own support agent
  • explain failures with PayPal's current SDK (APIMatic ContextMatic)
the wall
AI output never reaches a verdict

Plain code is used to…

  • decide every pass, fail or inconclusive from PayPal's records
  • check PayPal's signatures, ownership and the owner's passkey
  • enforce budgets, wallet limits, time limits and the stop button
