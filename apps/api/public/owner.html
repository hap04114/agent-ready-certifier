PayPal sandbox only

The A2 test, after the fix: an AI shopper that wants to spend more than its limit can only ask. The owner approves with a passkey (Windows Hello, Touch ID, a phone or a security key). The agent can read every email and code it is given, but it cannot make a passkey signature, so the bypass from the inbox-code version is gone. The certifier checks the signature; plain code then decides the verdict from PayPal's records.
